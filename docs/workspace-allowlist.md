# 本機白名單備註

本機使用 `workspace-allowlist.local.json`，不納入 Git。依使用者指定，目前內容為：

```json
{
  "schema_version": 1,
  "roots": ["/"]
}
```

- `/` 代表這台 Mac 檔案系統下的所有工作目錄，包括 Code 以外的本機資料夾；不會自動套用到其他電腦。
- 白名單只決定子代理建立時是否符合 MRH 分級範圍，不增加檔案讀寫權限、不繞過 sandbox，也不保證每次委派都會更換模型。原本的啟用、外送、角色及明示模型／推理強度保護仍適用。
- `roots: []` 代表沒有允許的工作目錄。只涵蓋一個專案時，填該專案的絕對實際路徑；它的子目錄也包含在內。
- 設定採嚴格 JSON，不能加入 `//` 註解或額外備註欄位；說明放在本文件。
- 新版來源程式在每次新的子代理建立事件讀取白名單；檔案失效時保留原委派，不放寬範圍。既有委派的結果紀錄不因之後修改白名單而丟失。

**目前僅完成本機檔案設定。** 日常 Codex App／CLI 的 Hook 接通仍在進行；這個檔案不會自行完成安裝或啟用。增加主模型使用子代理的方式另行討論，本次未更動相關規則。
