# 產品設計

開發、設計與驗收以根目錄[專案理念](../PHILOSOPHY.md)為參照；本文件說明具體設計與行為邊界。

MRH 在主 AI 準備委派子任務時提供難度與模型建議。它不替換宿主、不修改主聊天模型，也不自行建立另一套派工系統。

## 分級與選型

- 以 Light／Small／Mid／Top 表達任務難度，各宿主可配置有序候選模型與推理強度。
- Top 可選 Main（交回主 AI）或 Fixed（指定完整子代理 profile）。進階檔位可把四級機率換算成難度分數，再使用自訂檔位。
- 主 AI 保留最後選擇；使用者明示的模型、推理強度與專門角色優先，不因較便宜的建議而覆寫。
- 使用同一個 `mrh ctrl` 管理分級來源、候選、門檻與適用工作區，不從模型名稱猜測品質、價格或帳號使用權。
- Jev 為預設分級來源；現有 Codex／Claude 訂閱來源由明確設定選用，不自動跨來源回退。

## 外送與失敗處理

新設定停用且不允許外送。只有明確允許的工作區及符合原授權的任務可送往分級器；完整 brief、額外標題／角色和背景摘要仍須遵守各自外送界線。

普通分級的低信心、逾時或可恢復故障依宿主契約保留原呼叫並提供通知，不默默改用另一家模型。建議式 deny 是請主 AI 依建議重新派工的協定，不等於分類器故障。

選配 packet 對 release 結果未知的情況採停止與保留收據，不能重送可能已執行的外部作用。已知不可用的模型不得被保存為新的未確認選擇；查詢失敗本身不等於模型已下架。

## 統計與隱私

分級、建議、派工、原生確認與實際用量分開記錄。未知數值不補零，重讀統計不增加計數，重複事件依既有身分去重。Token 費用換算不是帳單，假設的節省不是實測收益。

一般統計不保存任務正文。Packet 的短期正文及獨立樣本收集器另有明確用途、權限、保留與清理契約，不應把它們誤認為普通統計資料。

背景摘要與 metadata 快照是可選接點。預設宿主 adapter 不讀外部專案私人記憶或 Monitor 資料庫；MRH 可獨立安裝與使用。

## 安裝與擴充

安裝器只操作選定的宿主，保留既有設定、統計、金鑰及其他 Hook。更新、回退與信任重新審閱的條件見 [安裝生命週期](install-lifecycle.md)。

新平台或宿主需要自己的安裝、原生事件與消費者驗證，不能只新增 catalog 或修改平台徽章便宣稱支援。擴充責任見 [新增宿主](host-extension.md)。
