## Origin and lifetime

The experimental launch/lease harness is macOS/POSIX-specific (`fcntl`); it is not a portable production entry or Windows support claim.

The owned Python driver supplies the producer executable path/hash, exact source/patch identities, bootstrap path/hash and registration context outside Hook stdin. It checks the actual modified source files against the two patches and hashes the executed artifact before and after its run. The Rust integration asserts its current executable is the registered producer. A fresh owned native configuration first discovers one untrusted command and then trusts only that command's `current_hash` using the supported native fixture API; trust bypass remains false. The driver reads back the actual command/key/hash. No installed host, global home, formal Hook or true account is modified.

Each registry invocation delegates fact preparation to the real patched `SpawnAgentHandler`; the integration fixture never supplies role/model facts. The real registry builds the Hook field and the native engine launches the registered MRH bootstrap with actual stdin. Role protection is obtained from the real parser and owned effort-only role file. An assertion in task arguments cannot supply host authority. The private adapter passes the actual export through the existing E7 strict parser and E6 typed facts, settings, factory, policy and Store; HTTP classification alone is scripted with a dummy credential.

The code-level owned registration and reviewed local process/configuration are the trust assumptions. Wire revision, IDs, `known` flags and nonce do not authenticate a process. This experiment excludes arbitrary hostile execution or file writes by the same operating-system owner; hashes are lineage checks, not universal attestation. There is no public production settings/CLI selector for this consumer. Production `SupportedHostResolver` stays unchanged and conservative.

The trusted parent holds a launch lock only while executing the registered producer. Actual invocation UUIDs select separate lease files containing exact call scope and original model/role/effort/fork binding, a single-admission marker and a short deadline. The Hook consumer checks launch/lease/input state at admission, classification response and output; close ends that exchange. Duplicate open preserves without modifying a live locked lease. Per-nonce files prevent one concurrent invocation's close from overwriting another. The overlapping-call proof is explicitly a guard fixture; the real host integration executes its cases serially.

Review found that merely replacing stdout after a midflight expiry could leave a cached Main in Store. The transport now checks the exchange before returning the classifier response, so the started synthetic attempt records a preserve failure. A later same-call replay must retain preserve without another transport request. Closing an exchange is not parent autonomous handback or Goal completion.
